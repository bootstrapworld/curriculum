== Building One-Level Decision Trees from Categorical and Quantitative Splits

_This section will make use of the following decision trees, which are defined at the bottom of the Definitions Area:_

- __A 1-level tree using only the *categorical* `"tail"` column__ +
`tree-c1 = build-tree(training, [list: "tail"], "species", 1)`

- __A 1-level tree using only the *quantitative* `"pounds"` column__ +
`tree-q1 = build-tree(training, [list: "pounds"], "species", 1)`
