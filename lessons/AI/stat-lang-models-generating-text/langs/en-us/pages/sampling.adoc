== Text Generation Exercise #1

@n Let's start our text generation with the word "she".

@indented{*Text Generation 1*:
@fitbruby{10em}{she}{first word} @hspace{1em}
@fitbruby{10em}{@ifsoln{swallowed}}{second word} @hspace{1em}
@fitbruby{10em}{@ifsoln{the}}{third word} @hspace{1em}
@fitbruby{10em}{@ifsoln{spider}}{fourth word}
}

@n Determine which word is most likely to follow "She " and record it on the line for second word above.

@n Determine which word is most likely to follow your first two words and record it on the line above for third word.

@n Use statistical language modeling to determine the fourth word.

@n Everyone in your class should have generated the *same* text. Why do you think that was the outcome?

@blanklines{3}{
@ifsoln{The corpus included a lot of repetition. Every single time we saw the word "She", it was followed by "swallowed". There were no instances when two different words had the same likelihood of following a given word.}
}


== Text Generation Exercise #2

@n Let's start our text generation with the word "spider".  Use statistical language modeling to determine the next word. @fitb{}{@ifsoln{"that" or "to"}}

@n How is this text generation example different from the last? @fitb{}{@ifsoln{There are two equally likely options instead of one most likely.}}

@n Use statistical language modeling to complete the two text generation options below.

@vspace{1em}

@teacher{
Some students will have the 2a response in the 2b blanks, and vice versa — which is fine!

}
@indented{*Text Generation 2a*:
@fitbruby{10em}{spider}{first word} @hspace{1em}
@fitbruby{10em}{@ifsoln{that}}{second word} @hspace{1em}
@fitbruby{10em}{@ifsoln{wriggled}}{third word} @hspace{1em}
@fitbruby{10em}{@ifsoln{and}}{fourth word}
}

@vspace{1em}

@indented{*Text Generation 2b*:
@fitbruby{10em}{spider}{first word} @hspace{1em}
@fitbruby{10em}{@ifsoln{to}}{second word} @hspace{1em}
@fitbruby{10em}{@ifsoln{catch}}{third word} @hspace{1em}
@fitbruby{10em}{@ifsoln{the}}{fourth word}
}

@n You've just generated two possible results. If you were a computer, which one would you suggest. Why?

@blanklines{2}{
@ifsoln{Computers can't choose unless they are given a rule to follow. Since text 2a and text 2b are equally likely, a computer would need another criteria to fall back on, perhaps whichever come first alphabetically.}
}
