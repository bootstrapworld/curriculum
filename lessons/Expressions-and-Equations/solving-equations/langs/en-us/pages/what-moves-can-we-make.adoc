@center{ @big{ @math{x + 8 = 26} } }

Try to transform the equation above, using each of the properties below. If a property cannot be applied, write "Not Applied" (or "N/A").

[.FillVerticalSpace, cols="<.^1,^.^4a,^.^10a,^.^12a",stripes="none", options="header"]
|===
|
| Property
| Transformed Equation
| Can it be used? If used, is it helpful?

| @n
| Commutative
| @math{8 + x = 26}
| Swapping 8 and x isn't helpful

| @n
| Associative
| N/A
| Can't be used, since neither side of the equation has more than two terms.

| @n
| Additive Identity
| @ifsoln{ @math{x + 8 = 26 + 0}, +
@math{x + 8 + 0 = 26}, +
etc. }
| @ifsoln{ Not helpful: the equation is no closer to being solved }

| @n
| Multiplicative Identity
| @ifsoln{ @math{1 \times (x + 8) = 26}, +
@math{x + 8 = 26 \times 1}, +
etc. }
| @ifsoln{ Not helpful: it only makes the equation more complicated! }

| @n
| Additive Inverse
| @ifsoln{ @math{x + 8 + (−8) = 26 + (−8)} }
| @ifsoln{ *Helpful!* Adding @math{−8} to both sides sets up @math{8 + (−8)}, which the Additive Inverse turns into 0, leaving @math{x} by itself }

| @n
| Multiplicative Inverse
| @ifsoln{ @math{\frac{1}{26} \times (x + 8) = \frac{1}{26} \times 26} +
which becomes +
@math{\frac{1}{26} \times (x + 8) = 1} }
| @ifsoln{ Not helpful: multiplying both sides by @math{\frac{1}{26}} lets @math{\frac{1}{26} \times 26} become 1 on the right, but it leaves a fraction multiplying @math{(x + 8)} on the left }

| @n
| Distribution
| @ifsoln{ @math{3(x + 8) = 3 \times 26} +
which becomes +
@math{3x + 3 \times 8 = 3 \times 26} }
| @ifsoln{ Not helpful: multiplying both sides by 3 and distributing leaves @math{x} further from being by itself }

|===
