= Compound Inequalities -- Practice

@do{
(define e1 '(and (< 2 5) (= 0 6)))
(define e2 '(or (> 6 8) (< -4 1)))
(define e3 '(and (string-equal "purple" "blue") (= (+ 3 5) 8)))
}

@lesson-instruction{
Create the Circles of Evaluation, then convert the expressions into Code in the space provided.
}

@n Draw the Circle for __2 is less than 5, and 0 is equal to 6.__

@showsoln{(coe e1)}
@showsoln{(code e1)}
@ifnotsoln{@vspace{12em}}

What will this evaluate to? Why? +
@blanklines{3}{
@fitb{}{@ifsoln{False. Only the first expression evaluates to true; "and" expressions check whether both expressions are true.}}
}

@n Draw the Circle for __6 is greater than 8, or -4 is less than 1.__

[.FillVerticalSpace, cols="1a", frame="none", options="noheader"]
|===
| @showsoln{(coe e2)}

@showsoln{(code e2)}
|===

What will this evaluate to? Why? +
@blanklines{3}{@fitb{}{@ifsoln{True. The second expression evaluates to true; "or" expressions check whether at least one expression is true.}}
}

@n Draw the Circle for __The String `"purple"` is the same as the String `"blue"`, and 3 plus 5 equals 8.__

[.FillVerticalSpace, cols="1a", frame="none", options="noheader"]
|===
| @showsoln{(coe e3)}

@showsoln{(code e3)}
|===

What will this evaluate to? Why? +
@blanklines{3}{
@fitb{}{@ifsoln{False. The first expression evaluates to false.}}
}
