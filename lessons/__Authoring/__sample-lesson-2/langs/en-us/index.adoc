== Inline Quiz Directives (demo)

=== Overview

This section produces three assessments: two checkpoints (one after
Launch, one after Investigate), and a cumulative one combining both
checkpoints' questions. See `README-mdquiz.adoc`'s "Writing an assessment
inline" section for the full reference on each directive used below.

=== Launch
@slidebreak{Launch}

@shortAnswer{optional}{0..360}{How many degrees are in a right angle?}{90}

@multipleChoice{sorted}{Which of these values is negative?}{
- [ ] 12
- [x] -4
- [ ] 0
- [ ] 7
}

@checkpoint{Inline Quiz Demo Checkin}

=== Investigate
@slidebreak{Investigate}

@cardSort{}{Match each histogram with the appropriate descriptive statement.}{
1::
- @image{images/boxplot.png}
- has a peak in the center
2::
- @image{images/boxplot2.png}
- has an outlier on the right
}

@categorize{Distinguish between bar charts and histograms.}{
Histogram::
- HISTOGRAM
- uses quantitative data
Bar Chart::
- BAR CHART
- uses categorical data
}

@checkpoint{Inline Quiz Demo Investigate}

@cumulativeAssessment{Inline Quiz Demo}

Once built, @assessment{inline-quiz-demo-checkin}, @assessment{inline-quiz-demo-investigate}, and @assessment{inline-quiz-demo} link to the Launch checkpoint, the Investigate checkpoint, and the cumulative assessment respectively.
