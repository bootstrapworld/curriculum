== Inline Quiz Directives (demo)

=== Overview

This section produces three assessments: two checkpoints (one after
Launch, one after Investigate), and a cumulative one combining both
checkpoints' questions. See `README-mdquiz.adoc`'s "Writing an assessment
inline" section for the full reference on each directive used below.

=== Launch
@slidebreak{Launch}
@objective{expressions-exponents}

blah blah blah @opt-starter-file{animals}.

@short-answer{optional}{0..360}{How many degrees are in a right angle?}{90}

blah blah blah

=== Investigate
@slidebreak{Investigate}

blah blah blah

@card-sort{}{Match each histogram with the appropriate descriptive statement.}{
1::
- @image{images/boxplot.png}
- has a peak in the center
2::
- @image{images/boxplot2.png}
- has an outlier on the right
}

@categorize{Distinguish between bar charts and histograms.}{
Histogram::
- HISTOGRAM
- uses quantitative data
Bar Chart::
- BAR CHART
- uses categorical data
}

blah blah blah


@teacher{Want to check for student understanding? Now is a good time to administer @checkpoint{Histograms, Visualizing Shape}. Alternatively, you can wait until the end of the lesson and use our cumulative assessment @assessment{Histograms}.}
