== Section M: fitb and blanklines adjacent, alignment check

This is the critical case: the ruled lines in blanklines must line
up with the underlines a stack of fitb lines would have produced.
blanklines is block-level and can never share a line with label text,
so the fair comparison is against BARE fitb lines (no @n/label prefix
sharing the paragraph) -- that's what a stack of fitb lines looks like
with nothing else on the line.

Three bare fitb lines, stacked:

@fitb{}{@ifsoln{alignment check line one}}

@fitb{}{@ifsoln{alignment check line two}}

@fitb{}{@ifsoln{alignment check line three}}

Immediately followed by blanklines with the same content, for
direct comparison:

@blanklines{3}{@ifsoln{alignment check line one, alignment check line two, alignment check line three}}

== Section N: fitb, fitbruby, and blanklines together in one exercise

[cols="^.^1a,^.^4a,^.^4a", stripes="none", options="header"]
|===
| | Input | Output

|@n
| @fitbruby{100%}{@ifsoln{2}}{x}
| @fitbruby{100%}{@ifsoln{4}}{y}

|@n
| @fitbruby{100%}{@ifsoln{3}}{x}
| @fitbruby{100%}{@ifsoln{9}}{y}
|===

@n What pattern do you notice? @fitb{}{@ifsoln{y = x squared}}

@n Explain your reasoning:

@blanklines{3}{@ifsoln{Each output is the input multiplied by itself, so the pattern is that y equals x squared.}}
